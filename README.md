# Data Canvas sample data

Two sample files to get started with Data Canvas.

1. Create a new workspace for each file.
2. Upload the file through the Data Library.
3. Ask one of the questions below.

Each block starts with standalone questions you can ask on a fresh workspace.
Lines marked "follow-up" assume you asked the question above them first, in
the same chat.

## olist_late_fixture.csv
Brazilian e-commerce orders, one row per order, with whether it arrived late.
Source: Olist on Kaggle, CC BY-NC-SA 4.0, reshaped into one table.

Questions:
- What share of orders arrive late, and which states are worst?
- What drives late delivery?
- Are cross-state orders later than same-state ones?
- Which product categories have the highest late rate?
- Build me a dashboard for tracking late deliveries.

Follow-ups questions you can try (ask after "What drives late delivery?"):
- Follow-up: is that still true if you only look at orders with more than one item?
- Follow-up: show that as a chart by seller state.
- Follow-up: which of those drivers can a seller actually control?

## ames_housing.csv
Residential sales in Ames, Iowa, 2006 to 2010. Public domain.

Questions:
- What are the main drivers of sale price?
- Which columns have too many missing values to trust?
- Is there a neighbourhood premium after accounting for size?
- Which sales look unusual compared to similar houses?

Follow-ups questions you can try (ask after "What are the main drivers of sale price?"):
- Follow-up: drop the size-related ones and show me what's left.
- Follow-up: does that change for houses built after 2000?
- Follow-up: turn that into a chart I can put in a slide.
